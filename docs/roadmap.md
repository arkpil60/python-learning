# Python Roadmap

- [ ] **0. Fundamentals Review:** execution, types, control flow, functions, basic collections.
- [ ] **1. Language Fundamentals:** objects, names, identity, mutability, expressions, scope, function signatures.
- [ ] **2. Standard Library:** strings, collections, iterators, `pathlib`, file I/O, JSON, exceptions.
- [ ] **3. Program Structure:** modules, packages, virtual environments, dependencies, testing, debugging, logging.
- [ ] **4. Data Model and Abstractions:** classes, dataclasses, generators, context managers, protocols, type annotations.
- [ ] **5. Data and Networking:** SQL, PostgreSQL, HTTP, APIs, `asyncio`, concurrency.
- [ ] **6. Backend Development:** Flask, blueprints, database access, authentication, testing, deployment.
- [ ] **7. Scientific Computing:** floating-point arithmetic, NumPy, SciPy, Matplotlib, numerical methods, simulations, verification.
- [ ] **8. Independent Project:** design, implementation, testing, documentation.
